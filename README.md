# 헬라어 단어 학습장 배포 안내
이 프로젝트는 한 개의 공개 웹 서비스로 배포하도록 구성되어 있습니다. 배포 후에는 여러 사람이 같은 단어·변화형·문장 문제를 학습할 수 있습니다.
## 공유 데이터와 개인 학습 기록
- **공유됨:** 과, 단어, 변화형, 문장 번역 문제, 학습자가 단어 입력 영역으로 추가한 단어
- **각자 분리됨:** 현재 카드 위치, 카드 앞뒤 상태, 퀴즈 진행, 오답 노트
개인 학습 기록은 브라우저에 설정되는 익명 학습 식별자를 기준으로 서버에 저장됩니다. 별도 회원가입은 없습니다. 브라우저 쿠키를 삭제하거나 다른 기기에서 접속하면 같은 개인 기록을 이어볼 수 없습니다.
## Render 배포
1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Render에서 저장소를 선택하고 새 Blueprint 배포를 만듭니다.
3. 저장소의 `render.yaml`을 사용해 서비스를 생성합니다.
4. 배포가 끝나면 Render가 제공하는 공개 주소를 공유합니다.
`render.yaml`에는 데이터가 유지되도록 1GB 영구 디스크가 포함되어 있습니다. 무료 또는 임시 디스크 환경에서는 서버가 다시 만들어질 때 데이터가 사라질 수 있으므로, 영구 디스크가 연결된 서비스로 운영해야 합니다.
## 운영 시 참고
- 단어·변화형·문장 문제는 모든 학습자에게 공통으로 제공됩니다. 개인별 카드 위치·퀴즈 상태·오답 노트는 브라우저별로 분리 저장됩니다.
- 배포 직후 Render 환경 변수에 자동 생성된 `ADMIN_PASSWORD` 값을 확인해 보관하세요. 화면의 관리자 로그인에서 이 비밀번호를 입력해야 단어를 추가하거나 관리 메뉴를 사용할 수 있습니다.
- 운영자가 원하는 비밀번호를 쓰려면 Render 서비스의 환경 변수에서 `ADMIN_PASSWORD` 값을 변경한 후 다시 배포하세요.
- 배포 주소가 만들어진 뒤에는 앱의 공유 버튼으로 해당 공개 주소를 전달할 수 있습니다.
